# Markdown examples

Sample files for `Alt m` (or `wt-md <file>`). Each one has a Mermaid diagram or two;
edit them and reopen to see how termaid draws your changes.

| File | Diagrams |
|------|----------|
| `flows/worktree-lifecycle.md` | flowchart |
| `flows/review-handoff.md` | sequence diagram |
| `design/zellij-panes.md` | class diagram, state diagram |
| `design/data/schema.md` | entity-relationship diagram |
| `planning/roadmap.md` | gantt chart, pie chart |

A block termaid cannot draw is shown as its Mermaid source, like this one:

```mermaid
this is not a diagram
```
